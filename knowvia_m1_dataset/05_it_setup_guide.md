# NovaTech IT Setup Guide

## New Laptop Setup
New employees should sign in using the temporary credentials supplied by IT, immediately change their password, and enroll in multi-factor authentication.

## VPN
Employees working outside a NovaTech office must use the company VPN when accessing internal systems.

If the VPN connection fails:
1. Confirm that the internet connection is working.
2. Restart the VPN client.
3. Re-authenticate using multi-factor authentication.
4. Restart the computer.
5. If the issue continues, contact the IT Service Desk.

## Email
Company email must be accessed through approved email applications.

## Software Installation
Employees should install software through the company software portal when an approved package is available.
