# Knowvia Agent — M1 Synthetic Company Dataset

This dataset represents a fictional company named NovaTech and is intended only for development and evaluation of the Knowvia Agent RAG project.

## M1 goal
Use these files to build:
1. document loading
2. text chunking
3. embeddings
4. vector storage
5. semantic retrieval
6. top-k result display

Do NOT build answer generation, agents, MCP, authentication, or ticket creation in M1.

## Important test case
The dataset intentionally does NOT define whether confidential company data may be entered into ChatGPT or another generative-AI service. A later milestone should learn to abstain rather than inventing such a policy.

## Ground truth
`m1_ground_truth.json` contains sample retrieval questions and expected source documents/sections.
