Create an employee account

Create a new directory record and sign-in account together. Existing directory-only identities cannot be overwritten here. Public registration is disabled in the secure deployment; those records require a separately supported registration workflow.

Use a unique ID and email. IDs may contain letters, numbers, dots, underscores and hyphens.
